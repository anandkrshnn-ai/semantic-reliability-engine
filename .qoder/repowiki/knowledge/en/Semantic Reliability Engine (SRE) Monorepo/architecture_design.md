The repository is a single `semantic_reliability` Python package distributed via `pyproject.toml`, with child modules organised by concern rather than by sub-package: `cli_and_core` exposes the Click CLI (`sre`) and programmatic `SemanticGuardrail` API; `benchmark_corpus` and `examples` provide frozen YAML contracts and fixture CSVs consumed by the guardrail; `docs` holds the authoritative SCOS v1.0 JSON Schema and specifications that all other children validate against; `scripts` scaffolds the 14-model benchmark corpus and runs two-engine/hybrid-router profiling; `tests` exercises every subsystem against in-memory DuckDB fixtures; `demo_and_deploy` wires the SCOS MCP server into a runnable agent plus Docker/Kubernetes manifests. Cross-child wiring is performed at install time through `[project.scripts]` entry points (`semantic-reliability`, `sre`) and shared runtime dependencies (sqlglot, pydantic, duckdb, jsonschema), so any child can load a SCOS contract from `benchmark_corpus/` or `examples/` and run it through the same AST normaliser + invariant checker.

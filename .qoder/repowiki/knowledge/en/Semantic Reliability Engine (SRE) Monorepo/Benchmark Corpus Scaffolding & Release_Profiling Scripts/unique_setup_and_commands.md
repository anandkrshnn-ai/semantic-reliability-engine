Requires a `GITHUB_TOKEN` environment variable or CLI argument for `create_release.py` / `update_release.py` (token needs `repo` scope). Corpus must be generated first via `python scripts/scaffold_corpus.py` then `python scripts/scaffold_holdout_corpus.py` before running any benchmark script. Benchmarks execute against the `benchmark_corpus/dev` and `benchmark_corpus/holdout` directories and write JSON scorecards to the repo root.

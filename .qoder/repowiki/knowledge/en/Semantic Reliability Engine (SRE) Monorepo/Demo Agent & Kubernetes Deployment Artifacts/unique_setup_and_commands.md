Local demo: `docker compose -f demo/docker-compose.yml up` runs both the SCOS MCP server (port 8000) and the analytics agent; the agent reads contracts from `benchmark_corpus/dev` relative to the repo root. Production deploy: apply `deploy/k8s/semantic_firewall_sidecar.yaml` after creating the `sre-metric-contracts` ConfigMap containing the YAML metric contract files under `/etc/sre/contracts`.
